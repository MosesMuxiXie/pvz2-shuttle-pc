## 2. 装载路径

`AudioCatalog::load(assetRoot)` 只认三处，任何一处缺失都抛 `audio catalog: <path>: <what>`：

| 顺序 | 来源 | 条数 | 说明 |
| --- | --- | --- | --- |
| ① | `<assets>/audio/audio_report.json` | 10 | 提取器清单：5 mp3 + 5 wav，带 `uuid`/`bytes`/`duration` |
| ② | `<assets>/audio/*.{wav,mp3,ogg}` 目录扫描 | 34 | 清单里漏掉的 26 首世界曲 + 8 个 wav sfx，按文件名排序、跳过已在 ① 的文件 |
| ③ | `<assets>/audio/obb/durations.json`（+ 目录兜底） | 21 | OBB 还原曲，秒数来自 `durations.json`；表里没列的 `.ogg` 也补进来 |

合计 **65 = 26 bgm + 18 sfx + 21 obb**，其中 10 条 `source="report"`、34 条 `source="scan"`、21 条 `source="obb"`。

- `Sound.file` 一律是**相对 assetRoot 的路径**（`audio/sfx_click.wav`、`audio/obb/MUSIC_*.ogg`），
  调用方统一拼 `catalog.assetRoot / sound.file`；这样同一份目录既能在 repo 里跑，也能在安装目录里跑。
- 缺文件不当异常：`present=false` 记进 `missing[]`，`--audio-audit` 因此 exit 1（§7 的 ghost 清单用例覆盖）。
- 重名 / 重文件在装载期就报错（`duplicate sound name …` / `duplicate sound file …`），避免后加的清单条目静默覆盖前面的。

## 6. 无设备降级证据

### 6.1 没有 SDL 的构建（`PVZ_ENABLE_DESKTOP=OFF`）

```
backend: stub (PVZ_ENABLE_DESKTOP=OFF)
device: audio backend stub: built without SDL (PVZ_ENABLE_DESKTOP=OFF)
{"bgm":26,"decoded":60,"deviceAvailable":false,"missing":[],"seconds":4475.916,"sfx":18,"sounds":65}
exit=0
```

`AudioBackend::create()` 在这种构建里返回 `NullAudioBackend`：`available()=false`，`playSfx/playMusic`
直接返回 false，`pump()` 空实现。**解码与审计完全不受影响**（60 个文件照样真解码），
所以 CI 上用 audit 构建就能验音频，不需要声卡。

### 6.2 有 SDL 的桌面构建（`PVZ_ENABLE_DESKTOP=ON`）

```
deviceAvailable: true
{"bgm":26,"decoded":60,"deviceAvailable":true,"missing":[],"seconds":4475.916,"sfx":18,"sounds":65}
exit=0
```

本机 `SDL_OpenAudioDeviceStream(SDL_AUDIO_DEVICE_DEFAULT_PLAYBACK, 48 kHz/float/stereo, NULL 回调)`
真的开到了设备（推流模式，`pump()` 按队列水位喂 512 帧块）。设备打不开时整条链路自动退回
`available_=false` 并把 `SDL_GetError()` 留在 `note()` 里，不会崩。

混音器另外有独立用例：`mixer: 512 frames from sfx_shoot, volume/mute produce silence as specified`
—— master 音量 0 与 mute 都必须真的静音，避免「音量旋钮转了但没生效」。

## 9. 与并发工作的关系（为什么有的构建会出现别人的红）

`native/tests/engine_test.cpp`（08:53:50）被**其他成员**改动，我在 08:20 与 08:24 的两次构建因此看到
`engine` 红，且两次断言的句子不同（先是 `a zombie inside RectTriggerRange must detonate the mine`，
后是 `a zombie outside the pack window must survive a chomp`）——同一个用例在两分钟内换了失败点，

- `engine_test` 只链接 `pvz_engine`（`target_link_libraries(engine_test PRIVATE pvz_engine)`），
  目标里没有任何 `pvz_audio_core` 目标文件，音频代码不可能进入这个二进制；
