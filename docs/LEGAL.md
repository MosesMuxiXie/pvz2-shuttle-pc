这些内容的版权属于 **PopCap Games / Electronic Arts** 与 **SHUTTLE 制作组**。
本项目与上述权利人 **没有任何授权、合作或背书关系**。

我们能做且已经做的：

- 明确标注非官方、非商业、粉丝复刻；
- 逐项列出素材来源（`docs/SOURCES.md`）；
- 不销售、不收费、不加入广告或内购；
- 提供下架渠道：任何权利人可通过 Issue 联系，我们会立即删除仓库与发行包。

## 2. 各方的协议可能如何适用

| 协议/条款 | 可能的影响 |
| --- | --- |
| EA 最终用户许可协议 / 服务条款 | 通常禁止对游戏素材的再分发与衍生作品公开传播；公开的二进制发行包可能不符合 |
| SHUTTLE 模组的发布说明 | 模组作者未声明开源许可；素材再分发需征得作者同意 |
| Gardendless 项目 | 上游未声明开源许可；从网页版提取的素材同样属于原权利人 |
| PvZ2 Fandom 维基 | 曲目版权归 EA；维基文本为 CC BY-SA，但音频不是 |
| GitHub 服务条款 / DMCA | 权利人可发起 DMCA 下架；仓库可能被禁用 |

## 3. 因此本仓库采用的策略

1. **仓库 Root 只提交源代码、文档与 `content/` 数据**，不提交 APK、OBB、`assets/`、`Music/`、`Renders/`；
2. 代码（`game/`、`tools/`、`tests/`）以 MIT 发布，这部分没有版权问题；
3. **Releases 中的安装包包含素材**，仅用于已合法拥有 SHUTTLE 模组的用户在本机复刻体验；
4. 建议：若你计划公开传播安装包，请先取得 EA/PopCap 与 SHUTTLE 作者的许可，或仅保留源码仓库。
